# Externe Kräfte mit `Remote Force`

Externe Kräfte verhalten sich analog wie externe Verschiebungen. Auch kann eine Geometrie auf ein externen Punkt gesetzt werden von dem diesmal eine Kraft angreift. Die Fläche kann dabei wieder verformbar oder als starr definiert werden.

Ein Beispiel dafür wäre die Belastung des Fahrradfahrers auf dem Sattel bei unserem Rahmenmodel:
