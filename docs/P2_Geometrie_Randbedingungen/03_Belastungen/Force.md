# Kräfte mit `Force`

Bei Kräften ist zu beachten, dass der Wert durch die gesamte Geometrie aufgeteilt wird. Würden wir zum Beispiel beim Lenker eine Kraft von 100 N auf beide Endbereiche (wo die Hände aufliegen) anbringen, würde sich die Kraft auf die linke Seite mit 50 N und auf die rechte Seite ebenfalls mit 50 N verteilen.

Weiterhin kann die Richtung der Kraft über `Definied By = Components` direkt in Koordinatenrichtung angegeben werden oder über `Definied By = Vector` direkt in eine gegebene Richtung angegeben werden. Die Richtung kann dabei durch folgende Geometrien definiert werden:

- zwei Punkte
- eine Linie
- eine Flächennormale
- Achse einer Bohrung

definiert werden kann.
