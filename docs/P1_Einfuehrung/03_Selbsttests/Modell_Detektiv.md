# Modell-Detektiv

Jedes Modell unten liefert ein falsches Ergebnis. Klicken Sie sich wie in ANSYS durch den Strukturbaum, prüfen Sie die Details und klicken Sie die Einstellung an, die den Fehler verursacht. Jeder Fall hat genau eine Ursache, Sie haben drei Versuche.

!!! tip "Vorgehen wie bei der Fehlersuche im eigenen Modell"
    Den Strukturbaum von oben nach unten durchgehen: Einheiten, Geometrie, Material, Materialzuordnung, Netz, Randbedingungen, Ergebnis. Siehe auch die [Fehler-Checkliste](../../00_FAQ/Fehler_checkliste.md).
