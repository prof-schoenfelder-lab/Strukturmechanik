# :material-puzzle: Baugruppen und Auswertung

Bisher bestand jedes Modell aus einem Bauteil. In diesem Praktikum kommen mehrere Bauteile zusammen: Wie werden sie verbunden, und was heißt das für das Ergebnis? Danach geht es um das, was nach jeder Rechnung ansteht: das Ergebnis prüfen, so darstellen, dass man es vergleichen kann, und erkennen, wann eine lineare Rechnung nicht mehr gilt.

!!! abstract "Lernziele"

    - [ ] Verbindungen zwischen Bauteilen: was Mechanical beim Import anlegt und welche Kontaktarten es gibt
    - [ ] Wie eine vorgespannte Schraube berechnet wird
    - [ ] Ergebnisse in fester Reihenfolge prüfen und vergleichbar darstellen
    - [ ] Erkennen, wann eine lineare Rechnung nicht mehr gilt
